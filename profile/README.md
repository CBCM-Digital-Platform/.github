## About

The **CBCM Digital Platform** is a digital solution designed to support Catchment-Based Clinical Mentorship through coordinated learning, mentorship, assessment, communication, reporting, supervision, and evidence-based clinical support.

The platform connects mentors, mentees, mentoring facilities, and health-system stakeholders through integrated web and mobile applications.

## Platform

The CBCM Digital Platform consists of:

| Platform | Technology | Purpose |
|---|---|---|
| 🌐 Web Application | Next.js + TypeScript | Administrative and management platform |
| 📱 Mobile Application | Flutter + Dart | Mentor and mentee mobile experience |
| ⚙️ Backend | Node.js + Express + TypeScript | Core APIs and business logic |
| 🤖 AI Service |  AI-assisted clinical decision support |
| 📚 Documentation | Markdown / Diagrams | Requirements, architecture and system documentation |

## Key Capabilities

- 👥 Mentor and mentee management
- 🏥 Facility and organizational management
- 📋 Needs assessment
- 🎯 Facility prioritization
- 🤝 Mentor matching
- 📚 Digital learning
- 📝 Clinical and competency assessment
- 🔄 Mentorship cycle management
- 📊 Progress monitoring and reporting
- 💬 Mentor–mentee communication
- 📱 Offline and low-bandwidth support
- 🔔 Notifications
- 🎓 CPD and certification
- 🧠 AI-assisted clinical decision support
- 📈 Administrative dashboards
- 🔐 Role-based access control

## Repositories

### 🌐 Web Application
`cbcm-web`

The web-based platform for administrators, health-system stakeholders, mentoring facilities, and other authorized users.

### 📱 Mobile Application
`cbcm-mobile`

The mobile application for mentors and mentees, including learning, mentorship, assessments, communication, and offline functionality.

### ⚙️ Backend
`cbcm-backend`

The core API and business logic layer powering the CBCM platform.

### 🤖 AI Service
`cbcm-ai-service`

AI services supporting evidence-based clinical decision support and knowledge retrieval.

### 📚 Documentation
`cbcm-documentation`

Central repository for business analysis, requirements, system use cases, architecture, diagrams, UI/UX documentation, and project decisions.
